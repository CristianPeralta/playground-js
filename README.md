# JavaScript Playground

A comprehensive collection of JavaScript and Node.js examples, templates, and best practices for modern web development.

## 🚀 Project Structure

```
.
├── architectures/       # Different architectural patterns
│   ├── event-driven-test/
│   ├── microservices-demo/
│   ├── queue-rabbitmq/
│   └── rest-vs-graphql/
├── frameworks/          # Framework-specific examples
│   ├── express/        # Express.js examples
│   └── nestjs/         # NestJS framework examples
├── shared/             # Shared resources and templates
│   └── templates/      # Quick-start templates
└── tools/              # Development tools and utilities
```

## 🏁 Getting Started

### Prerequisites
- Node.js 18+ and npm/yarn
- Docker (for containerized examples)

### Quick Start
1. Navigate to any example directory
2. Run `npm install`
3. Follow the example's specific instructions

## 📦 Available Templates

### Basic Templates
- `hello-node/` - Basic Express.js server
- `fs-tests/` - File system operations
- `promises-vs-callbacks/` - Async patterns
- `streams-demo/` - Node.js streams
